# 1C:EDT Universal Issue Linkifier

Универсальный плагин для **1C:Enterprise Development Tools (1C:EDT)** и **Eclipse**, превращающий номера задач и тикетов в интерактивные кликабельные гиперссылки во всплывающих окнах **Git Blame / Quick Diff**, в редакторах кода (модули BSL, XML, Markdown, Gherkin сценарии) и панелях Git.

---

## 💡 Возможности (v1.1.0)

* **Точная матрица областей применения (Scoping Matrix):**
  * Для каждого правила настраивается индивидуальный режим активации в дереве областей:
    * `—` (**Отключено** / DISABLED) — правило не активно в этой области.
    * `Всегда` (**ALWAYS**) — ссылка всегда подсвечивается и переходит по простому клику мыши (без удержания клавиш).
    * `Ctrl + Click` (**CTRL_CLICK**) — ссылка активируется только при удержании клавиши `Ctrl` (или `Cmd` на Mac).
* **Каскадное управление группами и быстрые кнопки:**
  * Переключение режима на корневом узле (например, *«Редакторы файлов»* или *«Всплывающие окна»*) каскадно переключает все дочерние элементы.
  * Кнопки быстрого применения: `[ Везде: Откл ]`, `[ Везде: Всегда ]`, `[ Везде: Ctrl+Click ]`.
  * Кнопка `[ + Добавить расширение... ]` позволяет динамически добавить любое расширение файла (например, `sql`, `json`, `1c`).
  * Остаточный fallback `* (Все остальные файлы)` — задает поведение для всех неперечисленных расширений файлов.
* **Сверхбыстрый маршрутизатор $O(1)$:**
  * Индексация правил по расширениям файлов и областям.
  * Динамический контроль маски модификаторов (`IHyperlinkDetectorExtension2.getStateMask()`): при отсутствии правил или когда правила требуют Ctrl, Eclipse не тратит ни единого такта процессора на холостые сканирования строк.
  * Анализируется только одна строка под курсором в момент наведения.
* **Синтаксическая фильтрация через RegEx Target Group:**
  * Если регулярное выражение содержит группу захвата (например, комментарий в BSL `^\s*//.*?\b(TSK-\d{6})\b`), гиперссылкой становится именно захваченный номер задачи `$1`, а не вся префиксная строка.
* **Два демонстрационных правила «из коробки»:**
  1. `Jira TSK (BSL комментарии)`: ищет задачи только в строках-комментариях `^//` модулей `.bsl` и только по `Ctrl+Click`.
  2. `Jira TSK (Везде, кроме BSL)`: ищет чистые номера `\b(TSK-\d{6})\b` во всех остальных файлах и всплывающих окнах `Git Blame` всегда без `Ctrl`.

## 🚀 Установка и обновление в 1C:EDT

### Способ 1: Онлайн-репозиторий обновлений (Рекомендуется)
1. В 1C:EDT откройте: **Справка** (*Help*) → **Установить новое ПО...** (*Install New Software...*).
2. В поле **Работать с** (*Work with*) вставьте URL:
   ```
   https://vvi3ard.github.io/edt-issue-linkifier/
   ```
3. Отметьте категорию **1C:EDT Universal Issue Linkifier**.
4. Нажмите **Далее** (*Next*) → примите условия лицензии → **Готово** (*Finish*).
5. При запросе доверия к сертификатам нажмите **Выбрать всё** и **Доверять выбранному** (*Trust Selected*).
6. Перезапустите 1C:EDT.
7. В дальнейшем обновления подтягиваются автоматически через **Справка → Проверить наличие обновлений**.

### Способ 2: Установка из локального архива (.zip)
1. Скачайте файл `com.github.vvi3ard.dt.linkifier.repository-1.1.0.zip`.
2. В 1C:EDT: **Справка** → **Установить новое ПО...** → **Добавить...** → **Архив...** → укажите zip-файл.
3. Завершите установку и перезапустите EDT.

## ⚙️ Настройка правил

Откройте: **Окно → Параметры → 1C:EDT → Ссылки на задачи (Issue Links)**.

Страница построена по принципу **Master-Detail**:
* **Сверху (Master):** таблица правил с возможностью добавления, редактирования, дублирования и удаления.
* **Снизу (Detail):** интерактивное дерево областей применения выбранного правила. Клик по колонке «Режим» переключает `—` $\rightarrow$ `Всегда` $\rightarrow$ `Ctrl + Click`.
* **Внизу:** интерактивный тестер регулярных выражений в реальном времени.
